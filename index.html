Firmware patcher beta · patch pack 

    
Adds extra features to your own copy of the official Alesis Strike v1.5 update files. Everything happens here in the browser; nothing is uploaded. The patch contains only new code and new artwork; the few settings records it needs are rebuilt from your own file.

How to flash
      
    
        
  1. Click Build and put into the updater folder. The patched files replace the two .syx files there, with the exact names the updater needs. The first time, the originals are also saved in a sub-folder Original v1.5 files.
    2. 
        
  2. Turn the module off. Hold RECORD while turning it on to enter update mode, and connect USB.
    3. 
        
  3. Open the folder (Copy folder path, then Win+R, Ctrl+V, Enter) and run Alesis Strike Firmware Updater.exe from there.
    4. 
        
  4. To go back to stock, click Put the original files back and run the updater again.
    5. 
        
  5. Without an updater folder: use Download, then copy the files next to the updater with the exact names (remove any " (1)" the browser added).

Module debug log test firmware only

    
Test (diagnostic) firmware sends short status lines over USB as SysEx F0 7D 53 4D … F7. They are collected here while this page is open and MIDI is connected (top right). The test firmware keeps its last lines and sends them whenever it sends MIDI, so tap a pad to collect them. It sends nothing to the module, so it can stay open while you install firmware.

Kit Screen Creator beta
      

    

      Moving and sizing the drums and cymbals
      
    
        
  • Select a piece: click it in the picture, or click its name under Drums and cymbals. A dashed circle shows the selected piece.
    • 
        
  • Move: click and drag it in the picture. For small steps, use the arrow keys (1 pixel), or Shift + arrow (5 pixels).
    • 
        
  • Resize: hover over it and turn the mouse wheel, or type a size in the size box.
    • 
        
  • On top / underneath: Bring forward / Send back. Cymbals always sit above drums.
    • 
        
  • Add a piece with the type list and Add; Remove it with the red button.
    • 
        
  • Colours: drums have a shell and a head colour; cymbals have a tone.
    • 
        
  • Choose which pad lights which piece on the right, and tick Show the hit glows to see them.
    • 
        
  • Undo / Redo (Ctrl+Z / Ctrl+Y) step back and forward through your changes. Reset goes back to the standard kit; Presets offers other starting layouts. Both can be undone.
    • 
        
  • When it looks right, click Save for patching, then build it in Tools → Firmware patcher.
    • 
      

      Keep pieces clear of the BPM box (top left), the MOD FW BETA label (top right) and the soft keys along the bottom.
    

    
Design the kit picture the module shows: drag a drum or cymbal to move it, use the mouse wheel over it to resize, and choose which pad lights each piece. The Firmware patcher builds this layout in when Custom kit screen is ticked. Everything here is drawn by Strike Companion or comes from your own picture.
